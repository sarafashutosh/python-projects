# Python Password Generator
## Overview
It is a simple Python program that generates a random password based on the number of letters, symbols, and numbers requested by the user.

## Features

- Choose the number of letters in the password.
- Choose the number of symbols in the password.
- Choose the number of numbers in the password.
- Generates a randomized password.
- Randomly selects characters from predefined character lists.
- Shuffles the generated password to create a less predictable character order.

## How It Works

1. The user enters the desired number of letters.
2. The user enters the desired number of symbols.
3. The user enters the desired number of numbers.
4. The program randomly selects characters from predefined lists.
5. The selected characters are combined into a list.
6. The characters are randomly shuffled.
7. The final password is converted into a string and displayed.

## Concepts Covered

- `random` module
- usage of list
- append function in list
- shuffling a list
- for loop
