# 🏝️ Rock Paper Scissors Game - Python Project

## 📌 Overview

**Rock Paper Scissors** is a beginner-friendly fun game 
built in Python.

Rock Paper Scissors is a simultaneous two-player game. 
You and the computer both choose one of three hand gestures. 
Rock beats scissors, scissors beats paper, and paper beats rock. 
Matching gestures draw.
---
## 🎯 Learning Objectives

This project focuses on core Python fundamentals, including:

* Lists Implementation
* Randomization and use of random function
* Indexing
* Conditional statements (`if`, `elif`, `else`)
* Logical operators (`and`, `or`, `not`)
* User input handling
* Control flow
* String manipulation
* Nested conditions

---

## 🕹️ How the Game Works

Select one choice among rock, paper and scissors.
* 0 for Rock
* 1 for Paper
* 2 for Scissors

Your choice against the computer 
determines the outcome of the game.
Rock beats scissors, scissors beats paper, and paper beats rock. 
Matching gestures draw.
